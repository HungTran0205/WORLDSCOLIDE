## System Summary

Combat is a **real-time auto-battler** with player tactical control over formation, targeting mode, and skill activation. Entities act on individual cooldowns driven by AGI and weapon speed; there is no shared initiative queue.

**One action per turn:** each entity either auto-attacks **or** casts a skill — never both. When a skill is ready (auto-cast or manually triggered) it **replaces** the basic attack that turn (`processEntityAction`, `combat-engine.ts`; mirrored in `combat-simulator.ts` for offline parity). So a buff cast (Bulwark/Aegis/Rally/Mark) deals no damage, and a damage skill lands a single skill hit instead of attack + skill.

**Skills start on cooldown:** an entity's `skillCooldownUntil` is initialised to the skill's `cooldownMs` at combat start, so the first cast only becomes available after one full cooldown has elapsed (`combat-entity-factory.ts`, `combat-simulator.ts`) — no opening-tick burst.

**Two execution paths share the same formulas:**
- **Arena (live):** `CombatEngine.tick(dt)` — `LOGIC_TICK_MS = 100ms` accumulator loop (`combat-engine.ts:33`)
- **Auto-resolve (offline/mission):** `simulateCombat()` in `combat-simulator.ts` — instant, same damage formulas

Hard cap: **120 seconds** real time per battle (`MAX_COMBAT_MS = 120_000` — `combat-engine.ts:34`).

## Skill Types & Multi-Target Mechanics

**Skill Type Schema** (`combat-types.ts: Skill.skillType`):

| Type | Behavior | Example |
|------|----------|---------|
| `'auto-attack'` | Single target (default) | Pierce, Snipe, Sunder |
| `'cleave'` | Primary + radial splash | Cleave: primary + ≤2 extra within 1.8u @ 0.6× |
| `'aoe'` | All ground enemies | Quake |
| `'self-buff'` | No target, caster effect | Rally, Aegis, Mark |

**Splash Damage** (`Skill.splashDamageMultiplier`):  
Cleave secondary targets take `baseDamage × damageMultiplier × splashDamageMultiplier`. Applied in `executeSkillCleave()` after primary hit lands. Bonus effects (crit, on-hit procs) only trigger on primary; splash targets cannot cascade into additional hits.

**Riposte Counter Flag** (`CombatEvent.isRiposte`):  
Counter-attacks generated by Riposte stance carry an `isRiposte: true` flag to distinguish them from normal hits. Used by VFX layer to render parry-flash effect (blue-white spark distinct from standard impact).

**Effect Routing** (`skill-event-resolver.ts`):  
Skill events route to the orchestrator via trigger type:
- `trigger: 'skill-use'` → damage events → impact VFX (Pierce, Cleave; hitstop, shake, mesh-FX, audio)
- `trigger: 'skill-buff-applied'` → buff grant → stance/warcry aura VFX (Rally: self-buff; no hitstop)
- `trigger: 'effect-applied:riposte'` → riposte counter → parry-glint on entering stance, parry-flash on counter-hit
