# Room: Tavern

**Def:** `src/game/data/facility-definitions.ts` — `FACILITY_DEFINITIONS.tavern`
**Systems:** `src/game/systems/tavern-audition.ts`, `tavern-negotiation.ts`, `tavern-spawn.ts`, `tavern-merc-lifecycle.ts`

## Purpose

Recruitment hub. Per in-game day (30 real min), 3 random visitors spawn. Player can recruit them permanently, hire as one-quest mercs, or skip (visitors despawn next day).

## Build Requirements

- Cost: 0 gold, **200 WOOD** (tutorial gate — forces first haul loop)
- Upgrades: +200g → Lv2, +400g → Lv3
- Available from guild Lv1 (built during tutorial `build-tavern` beat)

## Slot & Keeper

| Level | Member Slots | Vis Bonus | Daily Chars | Merc Cap |
|-------|-------------|-----------|-------------|----------|
| 1 | 1 | +2 | 3 | 3 |
| 2 | 2 | +4 | 3 | 3 |
| 3 | 2 | +6 | 4 | 4–5 |

**Primary stat:** CHA. Keeper is the 1 assigned slot.

Keeper stat impact:
- `CHA` — drives Negotiation stat → success rate
- `INT` — info visibility tier (how much is revealed about visitors)
- `LCK` — rare/legendary spawn bias
- Derived: `Negotiation = floor(CHA × 1.5 + INT × 0.5) + traitBonus + equipBonus`

## Visitor Spawn Pool

Each day the spawn pool is seeded deterministically per `(SaveID + InGameDay)` — anti-save-scum.

Visitor generated by:
1. Pick archetype (weighted by Tavern level)
2. Roll Rarity (1=Common → 5=Legendary; weighted by Tavern level + Keeper LCK)
3. Roll Faction (from unlocked factions)
4. Distribute 50 talent points (weighted toward archetype affinity)
5. Calculate `Demand = floor(CombatPower × 0.4) + Rarity × 5 + DailyMoodBias`

## Negotiation Formula

```
SuccessRate% = clamp(50 + (Keeper.Negotiation - Visitor.Demand) × 0.6 + Σ Modifiers, 5, 95)
```

**Key modifiers:** trait match (+10%), generic gift (+5%), personal gift (+15%), guild fame (0–+20%), tavern level (+2%/lv), recent refusal (-10% per attempt within 7 days).

**Refusal tiers** by margin: SUCCESS → tight SUCCESS → COUNTER-OFFER (merc at +20% fee) → SOFT REFUSE → HARD REFUSE → INSULT EVENT.

Roll is deterministic from seed — reload within same day cannot change result.

## Merc System

Mercs are temporary contracts, not guild members:
- Cannot assign to production rooms
- Cost paid upfront: `floor(PowerLevel × 2.0 + Rarity × 100)` gold
- Can only be sent on one quest; despawn on completion
- Death = "Defeated" — **does NOT enter Infirmary** (Tavern Rep -1)
- Surviving mercs get `veteran=true` flag → 5% re-appear chance, +20% recruit bonus if they return

## Info Visibility

`VisibilityScore = Keeper.INT + Tavern.Level × 2`

| Score | Revealed |
|-------|---------|
| <10 | Name, archetype, appearance |
| 10–19 | + Combat stats |
| 20–29 | + Talent stats |
| 30–39 | + Hidden traits, mood bias |
| 40–49 | + Exact Demand, preferred gift category |
| 50+ | + Faction preview, recommended play |
